# Nortivo private beta guide

Short notes for using and testing the Android app.

## What this app is

Nortivo brings money, food and daily activity into one place. This guide is for the private Android beta, so some phone features still need real-device testing.

## Install the beta

Copy the APK to your Android phone and open it. If Android asks, allow installation from the file app you are using. Keep Play Protect on.
