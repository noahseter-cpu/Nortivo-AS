## Remaining operational decisions, in priority order

1. **Release integrity and administrative access.** Identify the exact combined artifact. Inspect its public boundary, resolve all material test or browser findings, and verify private rollback access and a named MFA administrator. Keep consumed owner provisioning absent.
2. **Recoverable private records.** Select retention and deletion periods for transcripts, proofs, receipts, identity records, event logs and backups. Assign deletion and key custody. Complete a sealed-record restore and key-ring recovery rehearsal before real collection.
3. **Host activation and provider rights.** Validate the canonical security host first, followed by alias and legacy links. Record current commercial rights, plan capacity and funding before enabling each external capability. Keep unavailable capabilities closed.
4. **Support and incident ownership.** Noah is the named triage and release owner unless responsibility is explicitly delegated. Agree operator coverage, restricted log access, backup cadence and alert routing. Demonstrate delivery to the designated recipient before advertising monitoring or a submission channel.
5. **Ongoing maintenance.** Track patch advisories for the locked runtime and dependencies, expiring provider agreements, host certificates, capacity, revoked accounts and key age. Repeat recovery and denial tests following material changes.

## Capacity and cost

Local workflow verification used an isolated SQLite store and blocked external service calls. Existing hosting, database and commercial data contracts determine the production bill. A visible chat refreshes its session and reads its thread approximately every 20 seconds. This is about **360 function requests per continuously visible chat-hour** before messages, retries, admin activity and other site traffic. A checked-in, visible operator adds approximately **240 lease renewals per hour**. These are implementation-based estimates useful for checking the actual provider allowances. Database reads, writes, service logs, storage growth, retention and restore add separate costs.

The private owner IEX path grants no customer redistribution rights. Obtain written coverage for display, non-display analysis, AI use and redistribution where applicable. Record pricing, usage ceilings and ownership for hosting, Supabase, authorized feeds, email, Stripe, any AI provider and optional worker capacity against the actual account plan. The published plan catalog is customer pricing. Quotes, free-tier allowances, payment fees, taxes, log/backup plans and operator time require a separate cost estimate before purchase or activation.
